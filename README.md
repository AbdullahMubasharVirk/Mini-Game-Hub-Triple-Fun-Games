# Mini Game Hub: Triple Fun Games

Mini Game Hub is a C# .NET 10 Windows Forms desktop application that includes three games in one app: Quiz Master, Card Memory, and Tic-Tac-Toe.

## Games Included

### 1. Quiz Master
A quiz game with player progress, categories, scoring, high score saving, and answered question tracking.

### 2. Card Memory
A memory matching game with a level roadmap, player progress saving, timer, move counter, leaderboard, and 10 themed levels.

### 3. Tic-Tac-Toe
An extended Tic-Tac-Toe game with 3x3 and 5x5 board sizes, player vs player mode, player vs computer mode, match history, and statistics.

## How to Run

1. Open the project in Visual Studio.
2. Make sure the framework is set to .NET 10.
3. Build the solution.
4. Run the project.
5. The main menu will open and the user can choose one of the games.

## Project Structure

- `MainMenuForm.cs` — main menu interface
- `QuizForm.cs` — quiz game
- `MemoryGameForm.cs` — card memory game
- `TicTacToeForm.cs` — tic-tac-toe game
- `ResultHistoryForm.cs` — result history screen
- `GameResult.cs` — model for saved results
- `ResultHistory.cs` — saving and loading game results
- `MusicManager.cs` — background music system
